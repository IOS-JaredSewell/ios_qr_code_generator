# ios_qr_code_generator
Modern single-file PHP QR code generator with live preview, logo embedding, custom styling, PNG/SVG export, responsive glassmorphism UI, and advanced QR customization using qr-code-styling.

Features:

Live QR code preview
Custom QR styling
Rounded, classy, and dot-matrix QR styles
Branded center logo support
Adjustable logo sizing and padding
Independent corner styling
Custom color controls
PNG export
SVG export
Responsive modern UI
High error correction support
No database required
Single-file deployment
Preview

Installation
1. Clone Repository
git clone https://github.com/YOUR_USERNAME/ios_qr_code_generator.git
2. Enter Project Directory
cd ios_qr_code_generator
3. Run PHP Development Server
php -S 0.0.0.0:3000
4. Open In Browser
http://localhost:3000
Deployment

This application is fully self-contained.

Simply upload:

index.php

to any PHP-enabled web server.

No database configuration or server-side image handling is required.
